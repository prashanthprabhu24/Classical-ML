# Classical ML Lab — Notebook Pack

This is the initial notebook structure for a Classical Machine Learning implementation laboratory.

## Modules
1. Linear models
2. Trees and ensembles
3. SVM, nearest neighbors, and Naive Bayes
4. Dimensionality reduction
5. Clustering
6. Density estimation and anomaly detection
7. Association rules
8. Foundations, pipelines, evaluation, and online/semi-supervised learning

## Notebook standard
Each notebook has sections for definition, intuition, mathematics, proof/justification, assumptions, datasets, from-scratch implementation, library comparison, tests, hyperparameters, complexity, scaling, GPU suitability, and best practices.

## Important status note
These notebooks are structured learning workbooks with implementation TODOs, not a claim that every algorithm implementation is already complete. The next step is to fill and validate one algorithm at a time, beginning with linear regression and K-means.
